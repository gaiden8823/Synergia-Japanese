# Synergia 非公式日本語化MOD v18

Synergiaの会話・選択肢・UIの日本語訳を改善した非公式MODです。ゲーム本体が別途必要です。

## ダウンロード

**[日本語化MODをZIPでダウンロード](https://github.com/gaiden8823/Synergia-Japanese/archive/refs/heads/main.zip)**

上のリンク、またはこのページの緑色の「Code」→「Download ZIP」から入手できます。

## 初めて導入する場合

1. Synergiaを完全に終了します。
2. ダウンロードしたZIPを右クリックし、「すべて展開」で解凍します。
3. 解凍先の `Synergia-Japanese-main` → `game` フォルダーを開きます。
4. 次の**3ファイルをすべて**コピーします。
   - `00_renforge_patch.rpy`
   - `renforge_translations.rpy`
   - `zz_synergia_atm_fix.rpy`
5. ゲーム本体のインストール先にある `game` フォルダーへ貼り付けます。同名ファイルがある場合は、上書き前に別の場所へバックアップしてください。
6. いつもどおりSynergiaを起動します。

### コピー先の見つけ方

Steam版では、ライブラリのSynergiaを右クリックし、「管理」→「ローカルファイルを閲覧」を選びます。開いた場所にある `game` フォルダーがコピー先です。

配置例：

```text
Synergia/
├─ Synergia.exe
└─ game/
   ├─ 00_renforge_patch.rpy
   ├─ renforge_translations.rpy
   ├─ zz_synergia_atm_fix.rpy
   └─ （もともとあるゲームのファイル）
```

**3ファイルを直接入れてください。`game/game` のようにフォルダーを二重にしないでください。**

導入にRenForgeやローカルLLMは必要ありません。DBの配置や翻訳の再生成も不要です。

## 以前の版から更新する場合

1. ゲームと、起動中であればRenForgeを完全に終了します。
2. ゲームの `game` フォルダーにある上記3ファイルと、対応する以下のファイルを、ゲームフォルダーの外へ移して保管します。存在するものだけで構いません。
   - `00_renforge_patch.rpyc`
   - `renforge_translations.rpyc`
   - `zz_synergia_atm_fix.rpyc`
3. 新しいZIPを解凍し、上記の導入方法に従って3ファイルをコピーします。
4. ゲームを起動し直します。

ほかのゲームファイルやセーブデータを削除する必要はありません。

## 日本語にならない場合

- ゲームを完全に終了してから起動し直してください。
- コピーした場所と、実際に起動しているSynergiaの場所が同じか確認してください。
- 上の配置例と同じ場所に3ファイルがあるか確認してください。
- 古い版を使っていた場合は、更新手順に従って同名の古い `.rpyc` をゲーム外へ移してから再起動してください。

## MODを外す場合

ゲーム終了後、上記3ファイルと対応する同名の `.rpyc` をゲームフォルダーの外へ移してください。導入前に同名ファイルをバックアップしていた場合は、それを元の場所へ戻します。

## 制作方法

**RenForge v1.3.0とローカルLLMを使って翻訳し、ChatGPTで原文と訳文を照合して校正しました。**

約5,151件の翻訳データを対象に、別のセリフや他言語が混ざった箇所の修正、人名表記の統一、未翻訳の補完、不自然な文章の校正を進めました。表示に必要なタグ・変数も検証しています。

その後、実際のプレイで見つかった端末ニュースの英語表示、文字のはみ出し、ボタンのアイコンと文字の重なりを修正しました。Spyritは意味が伝わるよう、初出を「腕の端末〈Spyrit〉」、以降を「端末」と表記しています。

## 確認状況

- 制作者によるエンディングまでのプレイ確認済み。
- その後のv17表示位置調整とv18用語修正は、構文・データ照合を実施。変更後の通しプレイは未実施。
- 作業環境のRen'Pyは7.4.2.1292です。他のゲーム版での動作は未確認です。
- 日本語フォントはゲーム付属の `logotypejp_corpmin.ttf` を参照します。
