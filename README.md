# Synergia 非公式日本語化MOD v18

Synergiaの会話・選択肢・UIの日本語訳を校正した非公式MODです。ゲーム本体が別途必要です。

## 導入方法

1. ゲームとRenForgeを完全に終了します。
2. 既存の同名MODファイルと `.rpyc` をゲームフォルダーの外へバックアップします。
3. この配布物の `game` フォルダー内の3ファイルを、起動するSynergiaの `game` フォルダーへコピーします。
4. ゲームを起動し直してください。DBの導入やRenForgeでの再構築は不要です。

以前の版から更新する場合も、上記3ファイルをまとめて更新してください。
英語表示のままの場合は、ゲームの完全終了と、実際に起動したゲームの配置先を確認してください。
削除する場合は、この3ファイルと対応する同名 `.rpyc` をゲーム外へ移し、バックアップを戻してください。

## 修正内容

- セリフ混入・他言語混入・誤訳の修正、人名表記の統一、未翻訳の補完、文脈に沿った校正。
- 端末ニュースの日本語化・スクロール対応、文字やアイコンの重なりの調整。
- Spyritは初出を「腕の端末〈Spyrit〉」、以降を「端末」と表記。

## 確認状況
